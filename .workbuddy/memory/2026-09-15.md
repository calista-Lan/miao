# 2026-09-15 工作日志

## 更换像素猫形象（读懂猫 v0.4）

**问题**：原 `miao.js` 里的 `SPRITE` 用的是大块粉色"口鼻"（P 色横带），看起来像猪。

**改动**（只动 `miao.js`，`猫.html` / `mao.css` 未改）：
- `SPRITE` 重画为 24 列 × 23 行网格，关键特征：不对称三角猫耳（外缘竖直、内缘斜切，内含粉色耳廓）、5×5 大眼＋竖瞳（2×3）＋半格高光、小粉鼻（2 格，居中）、V 形猫嘴、额头与身侧虎斑条、白色口鼻与胸腹、两只前爪。
- 新增 `TAIL` 常量：尾巴改为**在身体之前绘制**（先画 3 格底色当描边，再盖本色），2 格宽从右后方卷起，比原来糊在精灵图里清楚得多。
- 新增胡须：`renderCat()` 里用 3 条 4px 细线从两颊伸出（颜色 `#8a7a6a`）。
- 眼睛全部改为网格坐标驱动：眼白在列 5-8 / 15-18（镜像列用 `23 - c`），行为 7-11。
  - 正常：竖瞳 2×3 跟随鼠标 (`drawPupil(px, pxq, PIX, 3)`)
  - 烦躁：盖住眼睛上两行只留缝 (`drawPupil(..., 2)`)
  - 开心：先用毛色盖掉整只眼再画 `⌒` 眼
  - 闭眼/眨眼：行为 9 的横线
- 精灵原点 `sy` 从 165 改为 130（精灵变高），`sx` 仍为 232。
- `hitTest()` 改为矩形判定：尾巴 `x 502-566 / y 370-458`（先判定），头部 `x 246-548 / y 124-374`。
- `FISH_TARGET_Y` 291 → 342（对齐新嘴部位置）；`headCenter()` y 250 → 258。
- 爱心/`!`/`Zzz` 粒子出生点整体上移 40-60px 到头顶上方。

**验证方式**（临时脚本用完已删）：
- Python + 手写 PNG 编码器（无第三方依赖）把网格渲染成图，反复迭代了 7 版造型；
- Node + 假 DOM（`vm` + Proxy 桩）真实执行 `miao.js`，跑 4441 帧 + 模拟摸头/逗猫棒/投喂/摸尾巴/换色/昼夜/睡觉，0 报错；
- `node --check miao.js` 语法通过。

**遗留**：`fixcat.js` 是旧版补丁脚本（针对老精灵的行列坐标），已失效，若误运行会改坏新精灵，下次可考虑删除。

## 生气状态 + 会说话的尾巴（读懂猫 v0.5）

**需求**：① 生气状态，猫右上角出现用户给的红色怒气符号（💢）+ 生气表情；② 尾巴按猫行为学改变姿态，如不耐烦时拍地板。

**怒气符号**：用自写 PNG 解码器把用户截图降采样成像素网格（24×24，见 `miao.js` 的 `ANGER`），绘制在 `sx+19*S, sy-5*S`，格宽 `S*0.29`（约 4px），带弹出（ease 1.4 过冲）+ 呼吸脉冲 + 抖动。旧的 12×12 版本太"方"，24×24 才还原出 4 个分离的月牙。

**尾巴系统**（`miao.js`）：删掉静态 `TAIL` 数组，改为 `computeTail(now)` 链式骨骼（7 节 × 1.75 格）：
- `TAIL_ROOT = {c:19.6, r:21}`，角度从"竖直向上"起算，`curl` 逐节弯曲，正弦行波 `freq/wave`，`Math.min(y, 23-w)` 贴地钳制；
- 10 种姿态 `TAIL_MODES`：relaxed/happy/flick/alert/annoyed/angry/asleep/eating/pounce/stalk，`tailMode()` 按状态优先级选择，界面右下角 `#tail-state` 实时显示行为学解释；
- 拍地板：annoyed 模式下 `slapLift()` 走"抬起→快落→贴地"，`impact` 帧触发灰尘粒子 `spawnDust()`、低频闷响 `playThud()`、整体 1-2px 震动 `state.tailJolt`；
- 摸尾巴的升级链：relaxed →(1.5s) flick 尾尖抽动 →(超时) annoyed 拍地板 →(不停手) angry 炸毛甩尾；alert 状态下摸尾巴 0.6s 也直接生气。

**生气表情**：直立耳整只绕耳根旋转 -75°（`rotatePt`/`triContains` 光栅化成"飞机耳"，先 `eraseSky()` 擦掉天空再重画头顶行）；眼睛盖成外高内低的斜线 + 半透明压低的眉毛；张嘴嘶叫露上下犬齿；身体压低 5px + 抖 1px；身体后退 56px；`playGrowl()` 低频吼。

**验证工装（已保留）**：`.workbuddy/tools/render-verify.js` —— Node + 假 DOM（`vm`）真实执行 `miao.js`，把 canvas 指令录下来自己光栅化成 PNG（含 save/restore 状态栈，否则 globalAlpha 会跨帧泄漏导致整帧发黑）。用法：
`node .workbuddy/tools/render-verify.js <miao.js 路径>`，输出各种姿态的 PNG + `result.txt`（状态机链路、灰尘粒子数、报错）。运行需先在脚本同目录建输出目录或改用绝对路径。
